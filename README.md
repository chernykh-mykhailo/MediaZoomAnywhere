# Media Zoom Anywhere (Chrome Extension)

Розширення для браузерів на базі Chromium (Google Chrome, Microsoft Edge, Brave, Opera, Arc) на **Windows, macOS та Linux**, яке дозволяє наближати та переміщувати медіаконтент (фотографії, відео, canvas) на веб-сайтах за допомогою комбінації **Ctrl (або ⌘ Cmd на Mac) + Колесико миші**, блокуючи випадкове гортання слайдів галереї чи масштабування всієї сторінки.

## Можливості

- 🍏 **Повна підтримка macOS:** працює і з мишкою (**Cmd ⌘ або Ctrl + Колесико**), і з трекпадом Mac (**жест pinch-to-zoom двома пальцями** або **двома пальцями з Cmd**).
- 🔍 **Зум під курсором:** збільшення фото та відео центрується точно на позиції курсора миші.
- ↕️ **Швидке переміщення фокусу (Wheel Pan):** коли медіа вже збільшено, звичайне колесико або свайп двома пальцями плавно рухає відео/фото вгору чи вниз.
- 🚫 **Блокування системного зуму та свайпів сайту:** перехоплення подій у фазі capture (`wheel`, `pointerdown`, `pointermove`), що блокує перемикання слайдерів на сайтах та вбудоване масштабування сторінки.
- 🖐️ **Переміщення збільшеного медіа (Pan / Drag):** коли медіа збільшено, затисніть ліву кнопку миші або трекпад для вільного перетягування.
- 🔄 **Автоматичне скидання при перегортанні:**
  - Зменшення коліщатком назад до 100%.
  - Подвійний клік на медіа або клавіша `Esc`.
  - Звичайний скрол без зуму або стрілки навігації (`←`, `→`).
- ⚙️ **Меню налаштувань (Popup):**
  - Вибір клавіші активації: `Ctrl / Cmd ⌘` (за замовчуванням), `Alt / Option ⌥`, або `Shift`.
  - Налаштування швидкості зуму та максимального наближення (до 25x).

## Встановлення (на Windows та Mac)

1. Завантажте або передайте другові папку з цим розширенням (`ScrollAnyWhere`).
2. Відкрийте браузер (Chrome, Brave, Edge, Arc) і перейдіть за адресою:
   `chrome://extensions/` (або `edge://extensions/`, `brave://extensions/`).
3. Увімкніть перемикач **«Режим розробника»** (Developer mode) у верхньому правому кутку.
4. Натисніть **«Завантажити розпаковане»** (Load unpacked).
5. Оберіть папку `ScrollAnyWhere`.
6. Готово!

## Гарячі клавіші та керування

| Дія | Windows / Linux | macOS (Mac) |
|---|---|---|
| **Наближення / віддалення** | **Ctrl + Колесико** | **⌘ Cmd + Колесико** (або жест Pinch двома пальцями на трекпаді) |
| **Переміщення фокусу вище / нижче** | **Звичайне колесико** (коли збільшено) | **Звичайне колесико / свайп 2 пальцями** |
| **Переміщення фокусу вліво / вправо** | **Shift + Колесико** | **Shift + Колесико** |
| **Вільне перетягування (Drag & Pan)** | **Затиснути ліву кнопку миші** | **Затиснути трекпад / ліву кнопку миші** |
| **Швидке скидання зуму** | **Подвійний клік** / **Esc** | **Подвійний клік** / **Esc** |
