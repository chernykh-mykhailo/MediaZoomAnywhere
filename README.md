# Media Zoom Anywhere (Chrome Extension)

Розширення для браузерів на базі Chromium (Google Chrome, Microsoft Edge, Brave, Opera), яке дозволяє наближати та переміщувати медіаконтент (фотографії, відео, canvas) на веб-сайтах за допомогою комбінації **Ctrl + Колесико миші**, блокуючи випадкове гортання слайдів галереї чи масштабування всієї сторінки.

## Можливості

- 🔍 **Зум під курсором:** збільшення фото та відео центрується точно на позиції курсора миші.
- 🚫 **Блокування системного зуму та свайпів сайту:** перехоплення подій у фазі capture (`wheel`, `pointerdown`, `pointermove`), що блокує перемикання слайдерів на сайтах та вбудоване масштабування сторінки.
- 🖐️ **Переміщення збільшеного медіа (Pan / Drag):** коли медіа збільшено, затисніть ліву кнопку миші для плавного перетягування.
- 🔄 **Автоматичне скидання при перегортанні:**
  - Звичайний скрол колесиком (без Ctrl) миттєво повертає зум у 100% і дозволяє погортати до наступного слайду.
  - Натискання стрілок на клавіатурі (`←`, `→`, `Esc`, `Space`) скидає зум.
  - Клік по навігаційних кнопках/стрілках слайдера скидає зум.
  - Зміна джерела зображення (`src`/`srcset`) через слайдер автоматично скидає зум.
- ⚙️ **Меню налаштувань (Popup):**
  - Вибір клавіші активації: `Ctrl` (за замовчуванням), `Alt`, або `Shift`.
  - Налаштування швидкості зуму (від 5% до 35% за крок коліщатка).
  - Налаштування максимального наближення (від 2x до 25x).

## Встановлення

1. Відкрийте браузер і перейдіть за адресою `chrome://extensions/` (або `edge://extensions/`).
2. Увімкніть перемикач **«Режим розробника»** (Developer mode) у верхньому правому кутку.
3. Натисніть **«Завантажити розпаковане»** (Load unpacked).
4. Оберіть цю папку проєкту (`ScrollAnyWhere`).
5. Готово!

## Гарячі клавіші та керування

| Дія | Комбінація |
|---|---|
| Наближення / віддалення | **Ctrl + Колесико миші** |
| Переміщення збільшеного фото/відео | **Затиснути ліву кнопку миші та тягнути** |
| Скидання зуму | **Подвійний клік**, клавіша **Esc**, або звичайне колесико |
